# Owner manual quote: source-relative spread (v0.2.96)

This release adds one research-only display field to the independently authenticated owner dashboard. It does not add any provider request, historical source, background timer, storage, accounts, orders, persistent paper fills or cost. The existing manually triggered Public source quote returns its same last/bid/ask and server-receipt timestamps, with the original sourceReportedOnly true, cacheRightsVerified false, paperFillEligible false, executable false, ordersEnabled false and transfersEnabled false flags.

**Source conditions.** The relative spread is shown only if the verified response already indicates both Public-reported sides had qualifying timestamps and were fresh at **server receipt**. Missing or undated sides and stale books display Unavailable. Crossed prices are rejected. The browser additionally refuses timestamps not in strictly timezone-aware UTC ISO-8601 format, calendar-impossible dates, and local-time timestamps. No device clock is used to declare a source quote fresh.

**Computation.** For valid source bid and ask, relative spread (bps) = (ask - bid) / ((ask + bid) / 2) × 10,000. The parser uses exact decimal-to-BigInt scaling (12 fractional places), with integer rounding to 0.01 basis point. This is a *source reference*, not a market fee, profit forecast, effective transaction cost, executable spread, guaranteed liquidity or paper-fill price. The server remains authoritative for account provenance and source freshness; the browser cannot confer rights.

**Test expectations.** Use synthetic Node evaluation of the shipped JavaScript parser to confirm ordinary and 12-decimal relative spreads, equal bid/ask, crossed books, missing/untimed/stale sides and invalid calendar/timezone strings. Static tests guard lack of auto polling, browser storage, extra source requests or order/transfer UI. The full backend/identity/tenant recovery suite remains mandatory for a merge.

**Permission and activation boundary.** Owner's previous same-account value comparison and actual MSFT source retrieval stay accepted. This display does *not* establish market-data cache or redistribution rights or production paper-fill permission. The dormant isolated paper wallet, sealed synthetic recovery, owner/family access architecture and existing paid Render deployment are unchanged. No actions with real funds are enabled.
